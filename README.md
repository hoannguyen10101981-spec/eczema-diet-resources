# Eczema Diet Record-Keeping and Evidence-Reading Resources

Reusable blank observation sheet and source-reading worksheet. These are educational templates, not clinical data, a validated diagnostic instrument, or a treatment plan.

The companion explanations are available at [Eczema Diet](https://eczemadiet.org/).

## Blank food-and-flare record

Copy the following into a UTF-8 file named food-and-flare-diary.csv and open it in a spreadsheet. Blank rows are writing space, not patient observations.

```csv
Date,What I ate,Skin reaction,Stopped or swapped,What I noticed
,,,,
,,,,
,,,,
,,,,
,,,,
```

| Field | Meaning |
|---|---|
| Date | Date of the observation |
| What I ate | Food consumed |
| Skin reaction | Observed skin symptoms, if any |
| Stopped or swapped | A change that already occurred, not an instruction to change diet |
| What I noticed | Context and uncertainty worth preserving |

Keep completed diaries private. Do not post personal health information in repository issues. A recorded association does not establish causation or food allergy. This sheet does not instruct anyone to eliminate or reintroduce foods.

## Evidence-reading worksheet

Use this exercise to examine a dietary claim against its original source. It is not a treatment recommendation.

| Question | Notes from the source |
|---|---|
| What exact claim am I checking? | |
| What is the original source URL and date read? | |
| Is it a trial, observational study, review, guidance, or product description? | |
| Who was studied, and in what setting? | |
| Was the intervention a food, swallowed supplement, or topical product? | |
| What comparator was used? | |
| Was the outcome an eczema score, a blood marker, itch, sleep, or something else? | |
| How long was follow-up? | |
| What limitations or uncertainty did the source report? | |
| Which part of the proposed claim was not tested? | |

### Completion checklist

- Keep population, route, comparator, outcome, and duration attached to the result.
- Do not silently relabel a blood-marker change as an eczema improvement.
- Do not silently relabel a topical ingredient result as evidence for eating that ingredient.
- Mark inaccessible sources unread instead of filling in details from memory.
- Do not use this exercise to choose a personal dose or diet.
